## 1. 逻辑缓冲 → TM1640 地址（参考 DisplayChangeData）

| 逻辑 | 含义 | TM1640 GRID 地址 |
|------|------|------------------|
| buf[0] | 十位（双 COM） | 8, 9 |
| buf[1] | 个位（双 COM） | 7, 6 |
| buf[2] | WiFi / 低风 / 中风 | 10 |
| buf[3] | 高风 / 超高速 | 15 |
| buf[4] | 制冷 / 除湿 | 0 |
| buf[5] | 送风 / 制热 / 定时 | 1 |

段码位序：A=bit7 … G=bit1（与参考 `N_0` 一致）。

右侧数字是 **TM1640 显存下标**（写 `0xC0+n`，对应规格书 GRID n+1），不是丝印 GR1–GR8。
未使用的显存 2–5、11–14 保持 0。

阶段 1A 扫描（`STAGE-1A-0.1.2`），每步只亮一个灯或一位数字：

1. `DISP wifi`
2. 模式：`cool` → `dry` → `fan` → `heat`
3. 风速：`low` → `med` → `high` → `turbo`
4. 数码管：十位 `0..9`，再个位 `0..9`
