## 协议要点（已从授权红外协议 doc 提取，实现时按此编码）

- 载波 **38 kHz ±1%**。
- 帧：引导码 + 系统码 + 识别码 + 校验码 + 尾码；数据 **120 bit**，第 121 位为尾码。
- 系统码 **`01010110B`（`0x56`）**。
- 识别码字节 **A…M**，校验字节 **N**：系统码与识别码按文档做 4 位加和。
- 发送位序文档同时出现「高位先」与「低位先发」，**实现时以该 doc 正文为准并在日志里写明采用的一种**；不从旧工程抄位序。
- 与 1C 已有功能的对照（本阶段要接到同一套 RAM 设定）：
  - A7–A0：设定温度；16℃=`01101100` 起。
  - D6–D4 模式：**表内** 001 制热 / 010 制冷 / 011 除湿 / 101 送风（100 自动：本机无自动模式，收则忽略并打日志）。冻结稿曾把 001/010 写反，以 Word 表为准。
  - D1–D0 风速：00 关 / 10 低 / 11 中 / 01 高（红外无超快；超快保持本机键循环，红外不写入 turbo）。
  - E7–E6：开/关机。
  - 定时开/关相关位（D2/D3、H/I/J/K）映射到现有 0–24 h 定时；映射不清的位只打日志。
- 红外温度范围文档为 **61–90°F / 16–32°C**。本机按键范围仍是 1C 的 61–88°F / 16–31°C；红外超出则 **钳位** 到本机范围，不放宽按键限位。
- 摆风、睡眠、ECO、WiFi、童锁、GEN、L-GEAR、电辅热等 **本机无对应键** 的位：只日志、不发明新 UI。
- 室内环境温度在遥控 G 字节（实测值+20）：**不把该字节当作本机 NTC**。本机室内包走 P2.3 / AIN7（网名 `AD_NTC`）。10K 查表用用户提供的 `c_AD_TO_TEMPER_10K_TABLE`（下标 0–72℃，表值 8 位 AD）。
- 红外设定：A 为 ℃ 整数，I6 为华氏 +1；C→F **四舍五入**后再加 I6。去重含 A/D/E/I6/I7。I7=1 华氏 / 0 摄氏。
- 开机数码管默认环境温度（跟 C/F）；关机灭数字。调温（面板 +/- 或红外改设定/温标）预览设定 2 s。取消开机 15 s 数字屏保。
- PWR Byte3：有有效 NTC 后发室内 ℃+40（日志 `cur=ntc`）；此前仍发设定（`cur=set`）。开路/短路保持上次有效值。

红外输入脚：授权 PcbDoc + SOP28 手册确认为 **P3.2**（见 `docs/hardware-extract/ir_pin.md`）。P3.2 无外部中断，用 Timer1 采样。
