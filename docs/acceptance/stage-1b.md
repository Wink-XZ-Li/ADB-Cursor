# 阶段 1B 验收清单（实现前冻结）

版本标识（待编译后填写）：`STAGE-1B-0.1.0`  
基线：已验收 `STAGE-1A-0.1.2`

## 输入

- 阶段 1A 通过的工程、DispUart、Timer0、TM1640 段码表。
- 授权例外：仅从 `D:\嵌入式项目文件夹\ADB` 复制 `Sense_Lib` 及该库运行必需的触摸配置。
- 允许资料：官方头文件/手册、原理图、电控规格书（按键/蜂鸣相关页）。
- 不读取旧工程 HMI、按键业务、显示逻辑、整板初始化、通信协议。

## 本阶段不做

本地设定闭环（1C）、电源板协议、红外、涂鸦、OTA。  
不改芯片 Option / 烧录器配置。

## 交付物

- 已登记来源的 Sense_Lib 副本（仅触摸采集/初始化/通道配置）。
- 按键事件日志（可区分通道或键名）。
- 按键触发蜂鸣的可听验证。
- 编译 HEX、校验值、复制范围记录。
