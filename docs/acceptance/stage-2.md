## 协议要点（已从授权 docx 提取，实现时按此编码，不抄旧工程）

链路：UART 4800 8N1，脚位 P4.4 TX / P4.5 RX。USCI 编号以 8763 手册为准后再初始化。

| 方向 | 帧头 | 长度 | 校验 |
| --- | --- | --- | --- |
| 内→外（面板→电源板） | `0x66 0x99` | 21 字节（Byte0–20） | Byte20 = Byte0…19 之和（8 位） |
| 外→内（电源板→面板） | `0x55 0x5A` | 33 字节（Byte0–32） | Byte32 = Byte0…31 之和（8 位） |

内→外关键字段：Byte2 设定温度（℃+40）；Byte3 当前温度（℃+40，1C 无室内 NTC，发设定值并在日志标明）；Byte4 低 4 位模式 0 除湿 / 1 送风 / 2 电辅热 / 3 制冷，高 4 位风速 0 关 / 1 低 / 2 中 / 3 高 / 4 超快；Byte5 bit0 开关机。

与 1C HMI 对照：cool→3，dry→0，fan→1，heat→2；low/mid/high/turbo→1/2/3/4；关机风速发 0。华氏设定先换算成 ℃ 再 +40。

## 冻结的产品决策（阶段 2）

| 项 | 本阶段取值 |
| --- | --- |
| 设定权威 | 面板 RAM 设定为发送值；不因失联改本地设定 |
| 失联 | 连续 5 s 无完整合法 `55 5A` 帧 → 日志 `PWR lost`；数码管显示 `--`（开机时），恢复后回到设定显示 |
| 故障显示 | 规格 E1/E2 若能与外机故障字节对应则显示；其余只打日志，不猜未证明的码表 |
| 周期 | 自主：约 100–200 ms 发一帧内→外（以实现时手册/帧时序为准，并记入日志） |

## 验收项

| 编号 | 行为 | 方法 | 预期 |
| --- | --- | --- | --- |
| A2-01 | 编译 | `scripts/build.ps1 -Rebuild` | 0 error；警告须解释 |
| A2-02 | 日志回归 | COM7 115200 | `STAGE-2-*`；DispUart 仍可读 |
| A2-03 | 口分工 | 源码 + 日志 | 4800 仅电源板；不初始化 WiFi UART |
| A2-04 | 发送 | 逻辑分析仪或电源板侧 / 日志 hex | 开机后帧头 `66 99`，校验正确；开关机/模式/风速/温度变化反映到对应字节 |
| A2-05 | 接收 | 接电源板 | 收到 `55 5A` 打日志（版本/机型/故障至少可见） |
| A2-06 | 失联 | 拔掉电源板通讯 | 约 5 s 内 `PWR lost` 且开机显示 `--`；接回恢复 |
| A2-07 | HMI 回归 | 目视 | 1C 按键/显示仍成立 |
| A2-08 | 蜂鸣 | 耳听 | 仍仅上电鸣；故障蜂鸣不做（规格故障鸣留给后续） |

不以「口线初始化成功」代替收发。不把旧工程帧当对照去抄代码。无电源板时允许只验发送波形 + 失联显示。
