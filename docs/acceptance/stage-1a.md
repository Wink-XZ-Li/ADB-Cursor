# 阶段 1A 验收清单（实现前冻结）

版本标识（待编译后填写）：`STAGE-1A-0.1.0`  
基线：已验收 `STAGE-0-0.1.0`

## 输入

- 阶段 0 通过的工程、DispUart、Timer0 时基。
- 允许资料：TM1640 规格书、HY-3129、HY-6007、ORBEK 原理图、官方 IO 约束。
- 不使用旧工程 `led_segment_map.md`。

## 本阶段不做

按键业务、蜂鸣逻辑、HMI 设定、电源板协议、红外、涂鸦、OTA、触摸库复制。

## 交付物

- TM1640 驱动（与业务分离）。
- 可单独点亮的测试序列，日志标明当前步。
- 实板段码/指示灯对照记录。

## 验收项

| 编号 | 行为 | 方法 | 预期 |
| --- | --- | --- | --- |
| A1A-01 | 编译 | `scripts/build.ps1` | 0 error |
| A1A-02 | 日志回归 | COM7 115200 | `STAGE-1A-*`，时基仍约 0.5 s 量级 |
| A1A-03 | 全亮/全灭 | 目视 + 日志步号 | 数码管与指示灯能明显全亮、全灭 |
| A1A-04 | 单网格/单位 | 目视 + 日志 | 能区分各位/各组，记录实际对应 |
| A1A-05 | 段码表 | 文档 | 根据实板填写，不写未测猜测 |
| A1A-06 | 口隔离 | 源码 | 仍不初始化电源板/WiFi UART |

资料与封装冲突时：以原理图走线 + 实板点亮为准，并记录与 8763 未引出脚说明的差异。
