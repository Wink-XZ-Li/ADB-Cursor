# 阶段 1C 验收清单（实现前冻结）

版本标识：待实现（`STAGE-1C-*`）  
基线：已验收 `STAGE-1B-0.1.2`（2026-09-07 15:31「阶段 1B 通过」）  
显示：沿用 1A 段码表 `docs/led_segment_map.md` / `disp_map.h`。定时灯：TM RAM 1、SEG4（丝印 GR8 / SEG4）。

## 输入

- 阶段 1B 通过的工程、Sense_Lib 触摸、P2.4 上电蜂鸣、DispUart、Timer0、TM1640。
- 允许资料：电控规格书操作说明（电源/风速/定时/模式/加减、屏保、温标）、1A 段码、1B 通道号日志。
- 不读取旧工程 HMI、设定状态机、显示刷新业务、电源板协议。

## 本阶段不做

电源板 UART（P4.4/P4.5）、WiFi UART（P2.1/P2.0）及涂鸦指令、红外、OTA、产测、品牌 PID、故障码联机、掉电 IAP 记忆。  
不改芯片 Option / 烧录器配置。  
按键仍不蜂鸣（规格书）。

## 交付物

- 六键功能对照表（丝印 ↔ `tk` 号），由实板填写，不从旧工程抄键表。
- 本地设定状态机：开关机、模式、风速、设定温度、定时、华氏/摄氏。
- 显示与本地设定一致（数码管 + 模式/风速/定时/WiFi 图标）。
- 编译 HEX、校验值。

## 冻结的产品决策（1C）

| 项 | 本阶段取值 | 说明 |
| --- | --- | --- |
| 状态权威 | 本机 RAM | 无电源板；显示只跟本地设定 |
| 上电 | 关机 | 规格「断电前记忆」本阶段不做；开机后默认制冷、中风、华氏 72 |
| 温标 | 出厂华氏；关机长按风速 3 s 切换 | 规格书 |
| 温度范围 | 16–31 °C / 61–88 °F | 规格书；长按加减连发 |
| 风速 | 超高 / 高 / 中 / 低循环；除湿固定低风 | 规格书；关机长按风速只切温标，不切风 |
| 模式 | 制冷 → 除湿 → 制热 → 送风 | 规格书；关机下模式键无效 |
| 定时 | 0–24 h；点按进入，闪烁时加减，再点按或 5 s 确认 | 规格书；关机定时=定时开，开机定时=定时关。到时仅本地切开关机，不发电源板 |
| 屏保 | 无键 15 s 只显示温度（TM1640 降脉冲亮度）；任意键唤醒 | 规格书。关机熄屏（电源键除外） |
| WiFi 图标 | 上电关机默认闪烁；关机长按电源 3 s 进入/重进闪烁 | 仅本地图标，不发模组。3 分钟后熄灭 |
| 蜂鸣 | 仅上电一声 | 规格书；配网/产测鸣声不做 |

## 验收项

| 编号 | 行为 | 方法 | 预期 |
| --- | --- | --- | --- |
| A1C-01 | 键位对照 | 实板丝印 + `KEY tk=` | 六键各有唯一 tk，写入 `docs/key_map.md` |
| A1C-02 | 编译 | `scripts/build.ps1 -Rebuild` | 0 error；警告须解释 |
| A1C-03 | 日志回归 | COM7 115200 | `STAGE-1C-*`；设定变化有可区分日志 |
| A1C-04 | 开关机 | 目视 + 日志 | 关机灭设定灯/温度；开机显示设定与模式/风速灯 |
| A1C-05 | 模式/风速 | 目视 | 对应图标；一次一态；除湿锁低风 |
| A1C-06 | 温度 | 目视 | 加减与温标符合范围；数码管显示设定值 |
| A1C-07 | 定时 | 目视 | Timer 灯与闪烁设定；确认后灯亮 |
| A1C-08 | 屏保/温标/WiFi 本地 | 目视 | 15 s 屏保；长按风速切 °F/°C；WiFi 灯可闪/灭 |
| A1C-09 | 口隔离 | 源码 | 仍不初始化电源板/WiFi UART |
| A1C-10 | 蜂鸣回归 | 耳听 | 仍仅上电鸣，按键不鸣 |

## 不做的验收缩水

不以「能出键」代替设定闭环。不把模组配网成功当作本阶段条件。不从旧工程抄默认温度/键表。
