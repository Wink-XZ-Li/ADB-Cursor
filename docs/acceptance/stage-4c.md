## 产品决策（已确认）

| 项 | 取值 |
| --- | --- |
| 上电 | 恢复断电前开关机（开着则继续开） |
| 设定 | 模式、风速、`fan_saved`、设定温度、温标 |
| 标志 | 睡眠、屏保一起恢复 |
| 不记 | 定时剩余、开机分钟 DP150、WiFi 状态、故障 |
| 空/坏块 | 出厂默认：关机、制冷、中风、72°F、睡眠/屏保关 |
| 存储 | 8763 **独立 6K EEPROM**（`IAPADE=0x02`），不改 Option，不写 APROM |
| 写入 | 设定变化后 **2 s 无再改** 再擦写扇区 0 |

规格原文：「按下启动电源，默认选择断电前记忆模式」。本阶段按完整断电记忆实现。

## 本阶段不做

MCU OTA、改 Option、A2-06 失联、品牌 PID、读旧工程 EEPROM 例程。

## 记录格式（EEPROM `0x0000`，12 字节）

`A5 5A` + `ver=1` + power/mode/fan/fan_saved/unit/sp/sleep/saver + 前 11 字节和。

## 日志

- `MEM miss`：无有效记录，用出厂默认。
- `MEM ok p= m= f= ts=`：装入成功。
- `MEM wr` / `MEM wr fail`：2 s 后写入结果。
