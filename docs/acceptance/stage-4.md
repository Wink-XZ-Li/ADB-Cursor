## 协议与脚位（已从授权 PDF / zip / Demo 提取）

- 模块串口 **9600 8N1**，帧 `55 AA`。PID **`uforlynlgj5xx3zg`**。
- 脚：**P2.1 TX / P2.0 RX = UART0**。波特率用 **Timer2**（Timer1 留给红外）。**P2.6 拉低** 给模块供电。
- 工作方式：MCU 处理 WiFi 灯和复位（zip 未开模块自处理）。灯语义按协议：配网闪、连上亮、未连灭。
- 官方 SDK 进工程的方式与 1B Sense_Lib 相同：只复制该 zip 的 `mcu_sdk/`，改 `protocol.c` 对接现有 HMI RAM；不抄旧 ADB。
- DP 对照见 `docs/hardware-extract/tuya_dps.md`。开关/温度/模式/风速/温标/当前温度/E1E2/睡眠标志/屏保/开机时长接到现有 RAM。
- 多入口：App 下发与面板、红外写同一套设定；随后电源板仍按阶段 2 发 `66 99`。
