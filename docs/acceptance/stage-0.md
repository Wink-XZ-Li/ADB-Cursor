# 阶段 0 验收清单（实现前冻结）

版本标识（待编译后填写）：`STAGE-0-0.1.0`  
基线：已验收 `STAGE-M1-0.1.0`

## 输入

- 阶段 -1 通过的工程与 DispUart Hello。
- 已知脚位、官方头文件/手册。
- 实测：COM7 @ 115200 可读，与按 32 MHz 计算的波特率相符。

## 本阶段不做

触摸库、显示业务/段码、HMI、电源板协议、红外、涂鸦、OTA。  
不改芯片 Option。工程 Flash 空命令若要改为 `SOC_8051_Driver` 下载，先说明再改。

## 交付物

- 硬件资源表：已确认 / 待测 / 本阶段不用。
- 用定时器的可核对时基（日志周期）。
- 仍仅用 DispUart 打版本与 tick。
- 编译 HEX、校验值、验收记录。

## 验收项（先写标准，后写代码）

| 编号 | 行为 | 方法 | 预期 |
| --- | --- | --- | --- |
| A0-01 | 资源表 | 文档 | 三路 UART、未引出脚、心跳脚分开标注来源 |
| A0-02 | 编译 | `scripts/build.ps1 -Rebuild` | 0 error；警告须解释 |
| A0-03 | 时基 | 外部串口量相邻 `tick` 时间 | 目标 500 ms，允许 400–600 ms |
| A0-04 | 日志回归 | COM7 115200 | 出现 `STAGE-0-0.1.0`，tick 递增 |
| A0-05 | 口隔离 | 源码 | 不初始化电源板/WiFi UART |
| A0-06 | GPIO | 可选目视 / 日志声明 | P0.4 仍翻转；不宣称一定是板上 LED |

## 不做的验收缩水

不以“自打印成功”代替串口间隔测量。时基不合格不得把 55 ms 改口称为目标行为。
