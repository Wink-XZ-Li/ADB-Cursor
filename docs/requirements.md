## 分类

**资料明确**

- 目标芯片 SC95F8763；工具链 Keil C51；烧录器 SC-Link。
- DispUart / 电源板 / WiFi 脚位见提示词。
- 数据手册：P0.5=USTX0，P0.6=USRX0；8763 未引出 P0.0–P0.3、P1.4–P1.7、P3.4–P3.7、P4.6–P4.7、全部 P5。
- USCI0 UART：OTCON USMD0=11；Mode 1；波特率 = fsys / BAUD1；TI/RI 写 1 清 0。

**需确认的产品决策（不阻塞阶段 -1，阶段 0/1C 前再问）**

- 控制状态权威、掉电记忆、温标、失联、红外范围、故障上报、OTA 恢复含义。

**需测量的硬件未知**

- 当前芯片 Code Option 主频是否为 32 MHz（影响波特率）。
- 板上是否有接到已引出 GPIO 的可见 LED；原理图无文字层，视觉识别互相矛盾。
- DispUart 实际 USB 串口号（主机可见 CH340 COM7，未确认接线）。
